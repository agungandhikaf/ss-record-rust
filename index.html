Konsep Flow

Next TC menandai TC aktif sebagai Done dan pindah ke TC baru. Mark Pending menandai TC aktif sebagai Pending, lalu lanjut ke TC baru. Untuk melanjutkan TC lama, klik Resume pada TC List.

Mode screenshot: Browser Area. Di Windows, aplikasi mencoba crop dari area address/search bar pada window aktif sehingga taskbar tidak ikut. Di Mac, aplikasi memakai crop offset fallback karena struktur window berbeda.
